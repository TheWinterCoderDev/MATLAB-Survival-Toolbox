
# Security Policy

## Supported Versions

MATLAB Survival Toolbox is an independently maintained
educational open-source project.

Security maintenance is provided on a best-effort basis.

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| Legacy implementations | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately
using GitHub Private Vulnerability Reporting.

Do not disclose sensitive security issues through
public GitHub Issues.

A vulnerability report should include:

- Description of the security issue.
- Affected version or commit.
- Steps required to reproduce it.
- Potential security impact.
- Suggested mitigation, if available.

Reports will be reviewed on a best-effort basis.

No guaranteed response or remediation time is provided.

## Numerical Correctness

Numerical inaccuracies and algorithmic defects
should normally be reported through GitHub Issues.

If a numerical defect also creates a security risk,
please use private vulnerability reporting.

## Engineering Disclaimer

This software is intended for educational and
research purposes.

It is not certified for production, industrial,
structural or safety-critical engineering applications.

All numerical results must be independently verified
before being used in real engineering projects.

## Responsible Disclosure

Please allow a reasonable opportunity to investigate
and resolve reported vulnerabilities before
public disclosure.
