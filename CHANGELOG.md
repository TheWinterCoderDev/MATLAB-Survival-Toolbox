
# Changelog

All notable changes to MATLAB Survival Toolbox
will be documented in this file.

The project aims to follow Semantic Versioning.

## [0.1.0] - Unreleased

### Added

- Modular numerical linear algebra module.
- Forward substitution solver.
- Backward substitution solver.
- Gaussian elimination with partial pivoting.
- Input validation and error handling.
- Six automated MATLAB unit tests.
- Reproducible linear system example.
- GitHub Actions continuous integration.
- Technical documentation for numerical methods.
- MATLAB-specific .gitignore configuration.

### Changed

- Modernized repository structure.
- Updated README documentation.
- Standardized function naming conventions.
- Established a development and release workflow.

### Legacy

- Preserved original academic MATLAB scripts
  under the legacy/ directory.

### Known Limitations

- Educational and research use only.
- No formal numerical stability guarantees.
- No condition number diagnostics.
- Limited test coverage.
- Not certified for safety-critical engineering
  applications.

## Future Development

### v0.2.0 — Nonlinear Equations

- Bisection method.
- Newton-Raphson method.
- Secant method.
- Review of the legacy Whittaker implementation.

### v0.3.0 — Numerical Approximation

- Polynomial interpolation.
- Taylor series.
- Numerical differentiation and integration.
